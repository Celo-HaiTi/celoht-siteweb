# Why We Chose Celo

CeloHT is built on the Celo ecosystem — not because we're committed to any blockchain for its own sake, but because of specific, practical characteristics that match the communities we serve.

## Mobile-first, by design

Celo was designed from the start for mobile access, which matters directly for our target communities: mobile phone use in rural and semi-rural Haiti is growing faster than traditional banking infrastructure. A network built assuming a desktop and a stable broadband connection would be the wrong technical foundation.

## Low transaction fees

Small, everyday transactions — the kind our agent network handles — need to stay economically viable. High gas fees would make cash-in/cash-out transactions impractical for the amounts involved.

## cUSD: a stablecoin built for daily use

Volatility is the single biggest obstacle to using a crypto asset for everyday spending. cUSD's peg to the US dollar removes that obstacle for the specific use case we care about: a participant receiving a remittance or a reforestation reward shouldn't have to think about price swings.

## What this doesn't mean

Choosing Celo doesn't make CeloHT a blockchain, a cryptocurrency project, or an investment platform. We're a user of this infrastructure, the same way a business is a user of the internet — present on it, dependent on it working, but not in control of it.
