# Governance

This repository follows the CeloHT ecosystem's shared governance model  - 
see the flagship repository's
[`GOVERNANCE.md`](https://github.com/Celo-HaiTi/CeloHT/blob/main/GOVERNANCE.md)
for the full, binding policy.

## Specific to This Repository

- **Content accuracy review**: any change to copy describing what CeloHT
  is or isn't (see `/about`, `/faq`, footer disclaimer) requires review
  from a maintainer familiar with the flagship repository's
  `docs/legal-status.md`, to keep the two in sync.
- **Design changes**: changes to the shared design tokens in
  `src/app/globals.css` should be considered ecosystem-wide, since the
  same tokens are used in the CeloHT dApp.

## Changes to This Document

Follow the same process as the flagship repository: a 14-day public
comment period and majority Maintainer Council approval.
